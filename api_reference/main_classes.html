Main classes¶

The forecasting classes accept wide dataframes with missing values to forecast. See the class docstrings for parameters, constraints, and executable examples.

class macroframe_forecast.MFF.MFF(df: DataFrame, forecaster: BaseForecaster | None = None, equality_constraints: list[str] = [], inequality_constraints: list[str] = [], parallelize: bool = True, n_forecast_error: int = 5, shrinkage_method: Literal['oas', 'identity', 'oasd', 'monotone diagonal'] = 'oas', default_lam: float = -1, max_lam: float = 129600)¶

A class for Macro-Framework Forecasting (MFF).

Forecast single-frequency time series data by generating initial forecasts and reconciling them to satisfy the supplied constraints while maintaining forecast smoothness.

Parameters:
dfpd.DataFrame

Input data in wide format, with periods in rows and variables in columns. Missing values indicate cells to forecast.

forecasterBaseForecaster, optional

An sktime forecaster. If omitted, the package’s default forecaster is used.

equality_constraintslist[str], optional

Linear equality constraints, expressed as strings that equal zero. Use ? as a wildcard to apply a constraint across forecast periods. Defaults to an empty list.

inequality_constraintslist[str], optional

Linear expressions interpreted as less than or equal to zero. Pass only the expression: "a? - 5" imposes an upper bound of 5 on a. Do not include a comparison operator such as <= in the string. Use ? as a wildcard to apply a constraint across forecast periods. Defaults to an empty list.

parallelizebool, optional

Whether to parallelize generation of the initial forecasts. Defaults to True.

n_forecast_errorint, optional

Number of pseudo-out-of-sample forecast windows used to estimate forecast errors. Defaults to 5.

shrinkage_method{“oas”, “identity”, “oasd”, “monotone diagonal”}, optional

Method used to shrink the sample covariance matrix. Defaults to "oas".

default_lamfloat, optional

Smoothing parameter used when observation frequency cannot be inferred from the index. A value of -1 estimates it empirically. Defaults to -1.

max_lamfloat, optional

Maximum smoothing parameter considered when estimating it empirically. Defaults to 129600.

Examples

>>> import numpy as np
>>> import pandas as pd
>>> from macroframe_forecast import MFF
>>> from sktime.forecasting.naive import NaiveForecaster
>>> periods = pd.period_range("2000", periods=20, freq="Y")
>>> values = np.random.default_rng(0).normal(size=20)
>>> df = pd.DataFrame({"a": values}, index=periods)
>>> df.iloc[-2:, 0] = np.nan
>>> model = MFF(
...     df,
...     forecaster=NaiveForecaster(strategy="last"),
...     equality_constraints=["a? - 5"],
...     parallelize=False,
...     n_forecast_error=2,
... )
>>> forecasts = model.fit()
Forecast 2 cells: ... seconds
Fill 4 in-sample cells: ... seconds
>>> np.allclose(forecasts["a"].iloc[-2:], 5.0)
True

Inequalities use expression-only strings, just like equalities. Here the unconstrained forecasts exceed 5, so the upper bound is binding.

>>> df["a"] += 10.0
>>> model = MFF(
...     df,
...     forecaster=NaiveForecaster(strategy="last"),
...     inequality_constraints=["a? - 5"],
...     parallelize=False,
...     n_forecast_error=2,
... )
>>> forecasts = model.fit()
Forecast 2 cells: ... seconds
Fill 4 in-sample cells: ... seconds
>>> np.allclose(forecasts["a"].iloc[-2:], 5.0)
True

Forecast and reconcile time series supplied at multiple frequencies.

The input mapping associates frequency codes with wide dataframes indexed by PeriodIndex. The fit method forecasts missing values and applies the supplied equality constraints across the frequencies.

Parameters:
df_dictdict[str, pd.DataFrame]

Dataframes keyed by frequency code, such as "Y" for annual or "Q" for quarterly observations.

forecastersktime.forecasting.base.BaseForecaster, optional

Forecaster used for the initial forecasts. Defaults to the package’s configured default forecaster.

constraints_with_wildcardlist[str], optional

Equality constraints written as expressions equal to zero. A ? wildcard applies the constraint across matching periods. Defaults to an empty list.

ineq_constraints_with_wildcardlist[str], optional

Inequality constraint expressions. This argument is retained in the constructor but is not currently applied by fit.

Examples

>>> import numpy as np
>>> import pandas as pd
>>> from sktime.forecasting.naive import NaiveForecaster
>>> from macroframe_forecast import MFF_mixed_freqency
>>> periods = pd.period_range("2000", periods=30, freq="Y")
>>> values = np.arange(1.0, 31.0)
>>> annual = pd.DataFrame(
...     {"a": values, "b": values * 2, "total": values * 3},
...     index=periods,
... )
>>> annual.iloc[-2:, 0] = np.nan
>>> model = MFF_mixed_freqency(
...     {"Y": annual},
...     forecaster=NaiveForecaster(strategy="last"),
...     constraints_with_wildcard=["a? + b? - total?"],
... )
>>> list(model.df_dict)
['Y']
